用近义替换、词根词缀与语境阅读，把一个单词连接到整个词义网络。

## 可以学什么

- 216 个精选词与词组，配原创例句、近义表达与使用边界。
- 英式 IPA、系统朗读、词根词缀拆解。
- 两类核心扩展：教材主题 60 词、真题阅读主题 60 词。
- 原创短文与解题依据；先作答，再看解析。
- 收藏、间隔复习和本机学习记录备份。

剑桥样章核验词与主题扩展分别标注。产品独立开发，不是剑桥完整词表或官方授权 App。
